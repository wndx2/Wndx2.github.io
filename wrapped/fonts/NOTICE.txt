  This is the deck's typeface on every device. It is hosted here rather than
  requested from the system so the design renders the same everywhere, and so
  the page makes no third-party network request.

Not here: SF Pro Rounded
  Earlier drafts reached for SF Pro Rounded via the CSS `ui-rounded` keyword.
  Apple's font licence restricts SF Pro to UI mock-ups for Apple-platform
  software and forbids embedding it in a web page, so no SF file ships here
  and the stylesheet no longer asks for it.
